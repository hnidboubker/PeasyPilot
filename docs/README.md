## Learning Path

**New to PeasyPilot?** Follow this recommended path:

1. **[Getting Started](./GETTING-STARTED.md)** (25 minutes)
   - Install PeasyPilot
   - Write your first test
   - Understand the basics

2. **Choose your testing style:**
   - **Unit Testing?** → [Unit Testing Guide](./GUIDES/unit-testing-guide.md) (30 min)
   - **Integration Testing?** → [Integration Testing Guide](./GUIDES/integration-testing-guide.md) (30 min)
   - **BDD Testing?** → [BDD Testing Guide](./GUIDES/bdd-testing-guide.md) (30 min)

3. **Learn framework specifics:**
   - [Framework Adapters Guide](./GUIDES/framework-adapters-guide.md) — xUnit vs NUnit vs TUnit

4. **Explore advanced topics:**
   - [Advanced Testing Patterns](./ADVANCED/testing-patterns.md)
   - [Performance & Optimization](./ADVANCED/performance-optimization.md)
   - [Troubleshooting & Debugging](./ADVANCED/troubleshooting-debugging.md)

5. **Consult references as needed:**
   - [API References](./REFERENCE/README.md)
   - [Error Codes](./REFERENCE/error-codes.md)
   - [CLI Reference](./REFERENCE/cli-reference.md)
