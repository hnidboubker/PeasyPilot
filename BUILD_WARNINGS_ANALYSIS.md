## 2. NU1507 - NuGet Package Source Configuration (~90 warnings)

### Impact
**Severity**: 🟡 Low  
**Type**: Build Configuration  
**Affects**: All 17 projects equally

### Error Message
```
warning NU1507: There are 2 package sources defined in your configuration. 
When using central package management, map your package sources with package 
source mapping (https://aka.ms/nuget-package-source-mapping) or specify a 
single package source. The following sources are defined: github, nuget.org
```

### Root Cause
`Directory.Packages.props` enables Central Package Management (CPM), but `Nuget.config` defines two sources without explicit mapping:
- `github` → private GitHub packages
- `nuget.org` → public NuGet registry

### Projects Affected (1 warning per project × 17 projects)
- src/PeasyPilot.BDD
- src/PeasyPilot.Bogus
- src/PeasyPilot.CLI
- src/PeasyPilot.Core
- src/PeasyPilot.Coverage
- src/PeasyPilot.Integration
- src/PeasyPilot.Moq
- src/PeasyPilot.NUnit
- src/PeasyPilot.TUnit
- src/PeasyPilot.Unit
- src/PeasyPilot.XUnit
- src/PeasyPilot.TestAssistant
- src/PeasyPilot.Generator
- samples/PeasyPilot.NUnit.Samples
- samples/PeasyPilot.TUnit.Samples
- samples/PeasyPilot.XUnit.Samples
- tests/PeasyPilot.Core.Tests
- tests/PeasyPilot.TestAssistant.Tests
- tests/PeasyPilot.Bogus.Tests
- tests/PeasyPilot.Generator.Tests

### Resolution Options

#### Option A: Configure Package Source Mapping (Recommended)
Edit `Nuget.config` to add explicit mapping:
```xml
<packageSourceMapping>
  <packageSource key="github">
    <package pattern="PeasyPilot.*" />
  </packageSource>
  <packageSource key="nuget.org">
    <package pattern="*" />
  </packageSource>
</packageSourceMapping>
```

#### Option B: Centralize NoWarn Suppression
Edit `Directory.Build.props` to add:
```xml
<PropertyGroup>
  <NoWarn>$(NoWarn);NU1507</NoWarn>
</PropertyGroup>
```

### Recommendation
**Use Option A** (package source mapping) to fix root cause rather than suppress.  
**Priority**: 🟡 Medium  
**Effort**: 30 minutes

## 3. CS0108 - Method Masking (3 warnings)

### Impact
**Severity**: 🟠 Medium  
**Type**: Code Quality / Language Feature  
**Affects**: 1 file (×3 frameworks)

### Details

**File**: `src/PeasyPilot.Integration/Fixtures/WebApplicationTestFactory.cs`  
**Line**: 49, Column 48  
**Method**: `WithWebHostBuilder(Action<IWebHostBuilder>)`

```csharp
// Current (causes warning)
public override IWebHostBuilder WithWebHostBuilder(Action<IWebHostBuilder> configure)
{
    // implementation
}

// Should be (with 'new' keyword)
public new IWebHostBuilder WithWebHostBuilder(Action<IWebHostBuilder> configure)
{
    // implementation
}
```

### Root Cause
The method overrides a base member from `WebApplicationFactory<TStartup>` but using only `override` keyword creates ambiguity. The `new` keyword makes the intent explicit: intentionally hiding the base implementation.

### Resolution
**Priority**: 🟠 Medium  
**Effort**: 5 minutes  
**Action**: Add `new` keyword to method signature

**Message**:
